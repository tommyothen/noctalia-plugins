# noctalia-plugins

My plugins for [Noctalia](https://github.com/noctalia-dev/noctalia). The repo is laid out as
a Noctalia plugin source, so it can be added directly to the shell rather than copied into
`plugins-local`.

## Plugins

| Plugin | ID | What it does |
| --- | --- | --- |
| [Away Mode](away-mode/) | `tommyothen/away-mode` | One toggle for stepping away: blocks suspend and lid-close, keeps lock and screen-off. |
| [Bongo Cat](bongocat/) | `tommyothen/bongocat` | The bar cat that slaps when you type, with your wpm next to it. Finds the keyboard itself, including the virtual one keyd emits on. |
| [Media Wallpaper](mediapaper/) | `tommyothen/mediapaper` | One picker for image and video wallpapers. Videos play through mpvpaper. |
| [Portrait](portrait/) | `tommyothen/portrait` | One toggle to turn a monitor sideways for vertical content, via niri output transforms. |
| [T3 Agents](t3agents/) | `tommyothen/t3agents` | Live dashboard for t3-code: subscription limits, active threads and agents, local and remote. |

## Installing

Add the repo as a git source and enable what you want:

```sh
noctalia msg plugins source add tommyothen git https://github.com/tommyothen/noctalia-plugins
noctalia msg plugins enable tommyothen/mediapaper
```

To hack on a plugin, clone the repo and add the checkout as a `path` source instead: `.luau` edits
hot reload, and changes to `plugin.toml` land on the next config reload.

## Layout

One directory per plugin, named after the part of the id that follows the slash, matching
the convention in
[community-plugins](https://github.com/noctalia-dev/community-plugins):

```
mediapaper/
  plugin.toml
  *.luau
  README.md
  translations/en.json
```

`catalog.toml` is generated by CI in the upstream repos and is gitignored here.

## Editor setup

`noctalia.d.luau` declares the plugin API for [luau-lsp](https://github.com/JohnnyMorganz/luau-lsp).
It lives in official-plugins and is gitignored here, so fetch a copy into the repo root:

```sh
curl -O https://raw.githubusercontent.com/noctalia-dev/official-plugins/main/noctalia.d.luau
```

`.vscode/settings.json` already points luau-lsp at it. `.luaurc` sets `nonstrict` mode to
match the `--!nonstrict` directive at the top of every script.

To check a plugin without an editor:

```sh
luau-lsp analyze --definitions=noctalia.d.luau mediapaper/*.luau
```
